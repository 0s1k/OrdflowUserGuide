# ייבוא הזמנות מאקסל

אם ההזמנות שלכם לא מגיעות מחנות מחוברת, אפשר להעלות אותן מקובץ Excel או CSV.

[:material-download: הורדת קובץ התבנית](../assets/files/ordflow-orders-import-template.xlsx){ .md-button .md-button--primary }

## שורה אחת = פריט אחד

כל שורה בקובץ היא **פריט אחד**, לא הזמנה אחת. כשבהזמנה יש כמה פריטים, כל פריט מקבל שורה משלו, ובכל השורות חוזר **אותו מספר הזמנה** (Order Id).

!!! example "לקוח הזמין חולצה ומכנסיים קצרים בהזמנה 1001"
    אלה **2 שורות**, ובשתיהן Order Id **1001**. מערכת Ordflow מאחדת אותן להזמנה אחת עם שני פריטים.

<div class="import-example" markdown>

| Order Id | Item (m) | Order Price (m) | Quantity (m) | Weight | Recipient First Name (m) | Recipient Country Code (m) |
|---|---|---|---|---|---|---|
| **1001** | T-Shirt | 25 | 1 | 0.2 | John | US |
| **1001** | Shorts | 30 | 1 | 0.3 | John | US |
| **1002** | Ceramic Mug | 40 | 2 | 1.2 | Anna | DE |

</div>

בטבלה מוצגות רק חלק מהעמודות. בקובץ התבנית יש את כולן.

!!! tip "חזרו על פרטי הנמען בכל שורה"
    מלאו את פרטי הנמען בכל השורות של ההזמנה, לא רק בשורה הראשונה.

## העמודות

בשמות העמודות, **(m)** פירושו חובה ו-**(o)** פירושו אופציונלי. בחלק מהעמודות אין סימון, לכן היעזרו בעמודה **חובה** בטבלה שלמטה.

| עמודה | חובה | מה למלא | דוגמה |
|---|:-:|---|---|
| **Order Id** | ✅ | מספר ההזמנה שלכם. אותו מספר בכל השורות של ההזמנה. | 1001 |
| **Item (m)** | ✅ | שם הפריט. | T-Shirt |
| **SKU (o)** | | מק״ט המוצר. | TS-RED-M |
| **Hs code** | ✅ | קוד המכס של הפריט (6 עד 10 ספרות). | 61091000 |
| **Order Price (m)** | ✅ | המחיר של השורה הזו (כל היחידות של הפריט). | 25 |
| **Currency (m)** | ✅ | קוד מטבע בן 3 אותיות. | USD |
| **Quantity (m)** | ✅ | מספר היחידות. | 1 |
| **Weight** | ✅ | המשקל הכולל של השורה. | 0.2 |
| **Weight Unit** | ✅ | יחידת המשקל. אם אינכם בטוחים, KG. | KG |
| **Order Date (m)** | ✅ | תאריך בפורמט DD/MM/YYYY. נדרש ליצירת ההזמנה. | 05/10/2026 |
| **Ship Date (o)** | | תאריך בפורמט DD/MM/YYYY. | |
| **Details (o)** | | הערות להזמנה. | |
| **Recipient Company Name (o)** | | שם החברה של הנמען. | |
| **Recipient First Name (m)** | ✅ | שם פרטי. | John |
| **Recipient Last Name** | ✅ | שם משפחה. אסור להשאיר ריק; אם אין שם משפחה, הזינו **-**. | Smith |
| **Recipient Country Code (m)** | ✅ או שם | קוד מדינה בן 2 אותיות. | US |
| **Recipient Country Name (m)** | ✅ או קוד | שם המדינה באנגלית. | United States |
| **Recipient City (m)** | ✅ | עיר. | New York |
| **Recipient State (mo)** | בחלק מהמדינות | חובה כשבכתובת יש מדינה או מחוז, למשל בארה״ב ובחלק ממדינות האיחוד האירופי. | NY |
| **Recipient postal code m** | ✅ | מיקוד. | 10001 |
| **Recipient Address 1 (m)** | ✅ | רחוב ומספר. | 350 Fifth Avenue |
| **Recipient Address 2 (o)** | | דירה, קומה, בניין. | Apt 12 |
| **Recipient Email (m)** | ✅ | מייל. | john.smith@example.com |
| **Recipient Phone (o)** | | טלפון. | +1 212 555 0100 |

!!! info "מדינה: קוד או שם"
    צריך **או** את קוד המדינה **או** את שם המדינה. אם מילאתם את השם, הקוד לא חובה.

!!! warning "שמרו על הפורמט של התבנית"
    - אל תשנו את שמות העמודות, אל תמחקו עמודות ואל תשנו את הסדר שלהן.
    - השאירו את התאים בפורמט **טקסט**, כמו בתבנית. כך לא ייעלמו אפסים בתחילת מיקודים וקודי מכס.
    - כתבו תאריכים בפורמט **DD/MM/YYYY**.
    - מלאו את הנתונים באנגלית (אותיות לועזיות).

## העלאת הקובץ

1. היכנסו למסך **Orders**.
2. לחצו על **Import** בסרגל הכלים העליון.
3. בחרו את הקובץ. אפשר להעלות קבצי **‎.xlsx**,‏ **‎.csv** ו-**‎.txt**. בקבצי CSV ו-TXT העמודות זהות לתבנית.
4. ההזמנות שיובאו יופיעו בעמודה **New**.

## איך קוראים את כרטיס ההזמנה

| בכרטיס | משמעות |
|---|---|
| **240** (למעלה משמאל) ו-**ID** | מספרים פנימיים של Ordflow. כדי לראות את **מספר ההזמנה שלכם**, לחצו על הכרטיס: ההזמנה תיפתח בחלונית מימין. |
| **2 X 2 items** | סך היחידות × מספר הפריטים השונים. בהזמנה 1001 יש 2 יחידות של 2 פריטים שונים; בהזמנה 1002 מופיע **2 X 1 items**: 2 יחידות של פריט אחד. |

## אם חלק מהשורות נכשלו

אם Ordflow לא מצליחה לייבא חלק מהשורות:

1. תופיע לכמה שניות הודעה קטנה בפינה השמאלית התחתונה, למשל **4 of 6 completed**.
2. יירד אוטומטית קובץ Excel עם השורות שנכשלו. בסוף כל שורה יש עמודה נוספת שמסבירה מה הבעיה.
3. תקנו את השורות האלה וייבאו שוב את הקובץ הזה.

השורות שהצליחו כבר נמצאות ב-Ordflow, אז אל תייבאו אותן שוב.
