# Order a Postal pickup outside the Center (DHL)

**Use this when:** the shipment goes by **Postal, outside Center**.

**Before you start:**

- [ ] All bags are labelled ([how](bag-labeling.md))
- [ ] Paperwork is printed ([how](paperwork.md))

## Steps

1. In Ordflow, open **_Pickups screen_**.
2. Select the shipments to be picked up.
3. Choose the pickup date and time window.
4. Confirm the pickup.
