# הזמנת איסוף מחוץ למרכז (DHL)

**מתי:** אתם שולחים **משלוח רגיל** (לא אקספרס) מ**מחוץ לאזור המרכז**. את האיסופים האלה מבצעת **DHL**.

**לפני שמתחילים:**

- [ ] המדבקות הופקו והודפסו ([איך](../orders/create-labels.md))
- [ ] כל השקיות מסומנות במדבקות ([איך](bag-labeling.md))
- [ ] המסמכים מוכנים ([איך](paperwork.md))

## בקשת איסוף

מחוץ למרכז אין טופס איסוף. שלחו מייל לכתובת **[ops@mailogs.com](mailto:ops@mailogs.com)**:

1. צרפו את מסמכי המשלוח. ראו [מסמכי משלוח](../orders/documents.md).
2. בקשו איסוף של DHL וציינו את כתובת האיסוף.

‏Mailog מזמינה את האיסוף מ-DHL בשבילכם.

**באזור המרכז?** ראו [הזמנת איסוף על ידי נהג Mailog](driver-pickup.md).
