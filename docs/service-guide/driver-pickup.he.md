# הזמנת איסוף על ידי נהג Mailog (אזור המרכז)

**מתי:** אתם שולחים **משלוח רגיל** (לא אקספרס) מ**אזור המרכז**. נהג של Mailog אוסף מכם את השקיות.

**לפני שמתחילים:**

- [ ] המדבקות הופקו והודפסו ([איך](../orders/create-labels.md))
- [ ] כל השקיות מסומנות ([איך](bag-labeling.md))
- [ ] המסמכים מוכנים ([איך](../orders/documents.md))

## הזמנת האיסוף

[הזמנת איסוף על ידי נהג Mailog](https://pickup.mailogs.co.il/order){ .md-button .md-button--primary }

מלאו בטופס:

| שדה | מה למלא |
|---|---|
| **שם חברה** | שם החברה שלכם. |
| **שם איש קשר** | את מי הנהג צריך לבקש. |
| **טלפון נייד** | מספרים בלבד. |
| **דואל** | לאן יישלח האישור. |
| **נא לבחור תאריך האיסוף** | יום האיסוף. ברירת המחדל היא מחר. |
| **הערות לאיסוף** | לא חובה, למשל קומה או כניסה. |

ואז לחצו על **Submit**. תקבלו **מייל שמאשר את האיסוף**.

![טופס האיסוף](../assets/img/service/pickup-form.jpg){ width="300" }
</figure>

!!! warning "איסוף לאותו היום: עד 09:00"
    איסוף לאותו היום אפשר להזמין רק עד **09:00**. אחרי השעה הזו, רק במקרים דחופים, שלחו מייל לשירות הלקוחות של Mailog.

**מחוץ למרכז?** ראו [הזמנת איסוף מחוץ למרכז (DHL)](dhl-pickup.md).
