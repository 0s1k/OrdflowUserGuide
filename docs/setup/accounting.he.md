## מספר עוסק {#vat-number}

בשדה **VAT #** הזינו את מספר העוסק המורשה שלכם, או את מספר ה-ח״פ אם אתם חברה. לחצו על **Save**.

## תיאור מכס אחיד (אופציונלי) {#customs-description}

ערוצי המכירה שלכם (Etsy,‏ Shopify ואחרים) שולחים ל-Ordflow את שם המוצר של כל פריט. שמות מוצרים הם לעיתים קרובות ארוכים, עמוסים במילות מפתח, או לא מתאימים להצהרת מכס. אפשר להחליף אותם בתיאור מכס אחד וקוד HS אחד בכל המשלוחים.

!!! success "השתמשו באפשרות הזו אם כל מה שאתם שולחים הוא מאותו סוג"
    למשל **חרוזי פלסטיק**, באדום, בכחול או בכל צבע אחר. תיאור אחד, *Plastic beads*, מתאר נכון כל משלוח.

!!! failure "אל תשתמשו בה אם אתם שולחים סוגים שונים של מוצרים"
    למשל **גרביים וכיסאות**. תיאור אחד לא יכול להתאים לשניהם, ותיאור מכס שגוי עלול לגרום לעיכוב המשלוח או להחזרתו.

**איך מגדירים:**

1. הזינו קוד מכס בשדה **HS Code** (בין 6 ל-10 ספרות).
2. הזינו תיאור באנגלית בשדה **Item Description**, למשל *Plastic beads*.
3. סמנו את **Set As Shipment Item Description**.
4. לחצו על **Save**.

## סוגי מע״מ (IOSS ואחרים) {#vat-types-ioss}

חלק מפלטפורמות המכירה גובות מע״מ מהקונה כבר בקופה. Etsy, למשל, עושה זאת בהזמנות לאיחוד האירופי ונותנת לכם **מספר IOSS**. הזינו כאן את המספרים האלה כדי שיצורפו למשלוחים שלכם.

<div class="hotspot-figure" markdown>
![אפשרויות VAT Type](../assets/img/setup/settings-vat-types.jpg)
<button class="hotspot" style="left:7.1%;top:71.6%" data-tip="בחרו את סוג המע״מ">1</button>
<button class="hotspot" style="left:31%;top:71.6%" data-tip="הזינו את המספר שקיבלתם מערוץ המכירה">2</button>

1. בחרו את סוג המע״מ ברשימה **Select VAT Type**.
2. הזינו את המספר בשדה שלידה.

אפשר לשמור כמה מספרים, אחד לכל סוג מע״מ שאתם צריכים. את המספרים מקבלים מערוץ המכירה (Etsy,‏ Shopify וכו׳).

| סוג מע״מ | למשלוחים אל |
|---|---|
| IOSS | האיחוד האירופי |
| GB-VAT | בריטניה |
| CHE | שווייץ |
| VOEC | נורווגיה |
| ABN | אוסטרליה |
| NZ-VAT | ניו זילנד |
