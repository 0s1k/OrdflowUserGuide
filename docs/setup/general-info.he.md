# פרטים כלליים

בלשונית **Settings ‹ General Info** נמצאים הפרטים הבסיסיים של הסניף.

| שדה | למה הוא משמש |
|---|---|
| **Branch Name** | שם החברה שלכם ב-Ordflow. לחצו על סמל העיפרון כדי לשנות אותו. |
| **Timezone** | אזור הזמן המקומי שלכם. |
| **Currency** | המטבע שבו מוצגים ערכי ההזמנות. ברירת המחדל היא דולר (USD). |
| **Week starts on** | היום הראשון בשבוע, למשל בדוחות. |
| **Length Unit / Weight Unit** | יחידות המידה לגודל ולמשקל החבילה (ברירת מחדל: ס״מ וק״ג). |

אחרי שינוי שם הסניף, אזור הזמן, המטבע או היום הראשון בשבוע, לחצו על **Save**.
